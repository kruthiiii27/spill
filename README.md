# SPILL ☕ — Anonymous College Confessions & Campus Tea Platform

> **Primary tagline:** "Got something to spill?"  
> **Supporting tagline:** "Your campus. Your stories. No names attached."

---

## 🛠 Tech Stack
- **Backend:** Python 3.10+ / Flask 3.0
- **Database:** SQLite (SQLAlchemy ORM abstracted for PostgreSQL migration)
- **Security:** Werkzeug password hashing, HTTPOnly sessions, Server-side authorization checks
- **Frontend:** Jinja2 dynamic rendering, Vanilla JavaScript, CSS3 variables, Editorial Design System
